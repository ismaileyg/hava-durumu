# 🌤️ Hava Durumu Uygulaması

## 📌 Proje Hakkında

Bu proje, **Visual Studio Code** kullanılarak geliştirilmiş modern bir hava durumu web uygulamasıdır.
Kullanıcılar istedikleri şehir için **anlık hava durumu verilerine** kolay ve hızlı bir şekilde erişebilir.

---

## 🚀 Özellikler

* 🌍 Şehir bazlı hava durumu sorgulama
* 🌡️ Anlık sıcaklık, nem ve hava durumu bilgisi
* ⚡ API üzerinden gerçek zamanlı veri çekme
* 💻 Basit, kullanıcı dostu arayüz
* 📱 Responsive tasarım (mobil uyumlu)

---

## 🛠️ Kullanılan Teknolojiler

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* REST API (hava durumu verisi için)
* Visual Studio Code

---

## ⚙️ Kurulum ve Çalıştırma

1. Bu repoyu klonlayın:

   ```bash
   git clone https://github.com/kullaniciadi/hava-durumu-app.git
   ```

2. Proje klasörüne girin:

   ```bash
   cd hava-durumu-app
   ```

3. `index.html` dosyasını tarayıcıda açın.

---

## 🔑 API Kullanımı

Bu proje bir hava durumu API’si kullanmaktadır.
Eğer API anahtarı gerekiyorsa:

* Kendi API anahtarınızı alın
* Kod içinde ilgili yere ekleyin

---

## 📈 Geliştirme Fikirleri

* 📍 Konum bazlı otomatik hava durumu
* 🌙 Karanlık mod (dark mode)
* 📊 5 günlük / haftalık tahmin
* ⭐ Favori şehirler ekleme
